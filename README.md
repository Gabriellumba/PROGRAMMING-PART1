This C# console application, developed as a Cybersecurity Awareness Assistant for South African citizens, educates users on identifying and mitigating online threats like phishing, weak passwords, and unsafe browsing. Built with a modular structure across
Program.cs
,
Response.cs
, and
LOGO.cs
, the program features custom ASCII art banners, multi-colored section borders, and a real-time character typing effect (
TypeWrite
) for an engaging console interface. Upon launch, it plays an introductory WAV voice greeting, greets the user by name, and executes an interactive keyword-driven chat loop with built-in input validation and fallback default responses to gracefully handle invalid entries or empty prompts.
